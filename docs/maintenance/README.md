# Espace de maintenance Bilocost

Cet espace centralise les anomalies observées, les corrections à réaliser et les contrôles à effectuer avant chaque mise à jour.

## Organisation

- `diagnostics/` : constats issus des vidéos et tests sur appareils.
- `backlog/` : liste priorisée des corrections à implémenter.
- `checklists/` : vérifications avant validation et déploiement.

## Règle de travail

Les constats sont documentés séparément du code. Aucune correction applicative ni aucun déploiement ne sont considérés comme réalisés tant qu'ils n'ont pas été implémentés, testés et validés.
